# TECNOVA - Soporte Personalizado

Aplicación de consola en C# para la gestión de incidencias técnicas, cálculo de presupuestos con extras, descuentos y consulta de estadísticas de caja.

## Instrucciones de ejecución

1. Abre una terminal en la carpeta raíz del proyecto (donde se encuentra el archivo `.csproj`).
2. Ejecuta el siguiente comando para iniciar la aplicación:
   ```bash
   dotnet run
   ```
